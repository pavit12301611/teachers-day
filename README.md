# teachers-day 💐

A heartfelt, **fully data-driven** Teachers' Day tribute site — made by **Pavit Singh**
(Class **IX-B**, roll **9231**) for the teachers and staff of **St. Mary's Academy** (83 members).
No frameworks, no build step, no paid services: just HTML, CSS and a little JavaScript. Host it anywhere.

## Pages

| Page | What's on it |
| --- | --- |

## The content engine — `js/data.js` 🧠

`js/data.js` is **generated from `staff.csv`** (`python3 /tmp/gen_staff.py` regenerates it — see below).
Every staff member is one record: name, designation, qualification, subject, theme colours,
`photo` (path inside `images/`) and `avatar` (initial avatar in `assets/staff-avatars/`).

- **Adding photos**: drop the real photos into the `images/` folder using the exact filenames from
  the CSV (`images/001_sr-sheela-solanki.jpg`, …). The site **automatically** uses them — until then
  it gracefully falls back to the initial avatars. No code changes needed.
- **Adding/removing staff**: edit `staff.csv`, re-run the generator, done.
- Per-person content (sealed letter, P.S. lines, message library, minigames) is built from
  subject/designation templates in `js/app.js` — personalised with each person's name.

No two visits are identical: quotes reshuffle, the P.S. line rotates, the daily wish changes with
the day of the week, and the letter greeting matches the time of day.

## Personalisation

Every staff member gets their **own** colour theme, **own** sealed letter, **own** P.S., **own**
minigame buttons (subject-flavoured: poems for English, proofs for Maths, elements for Science,
whistle for PE…) and **own** message library.

## Hidden surprises (4 per staff page 🕵️)

1. Tap the photo **5 times** → stickers + secret reveal
2. Find the **🎁 gift box** hiding in the footer
3. Select the **invisible ink** line in the footer
4. Enter the **Konami code** (↑ ↑ ↓ ↓ ← → ← → B A) → party mode + secret #4

Find all 4 on a page for the golden banner celebration. 🏆 Progress is saved per person in your
browser and shown on the staff index.

## The colour theme 🎨

The palette is tuned to the hand-drawn watercolour portraits: rainbow washes in the page
background, gradient headings, a rainbow navbar strip and marquee, colour-cycled card tints and
shadows, a painted halo behind profile photos and a colourful footer. It all lives in
**section 25 of `css/style.css`** (`--wc-*` tokens), so the whole scheme can be retuned from
one block of variables.

## The hand-out cards — one card, one teacher 🃏

`St_Marys_Teacher_Cards_A5-cards-2-per-A4.pdf` is the deck you print and hand over: **83 separate A5
landscape cards**, two to an A4 sheet, one straight cut down the dashed line and each teacher has
their own card in their hand. Nothing is shared between two cards.

```bash
python3 tools/build_staff_pdf.py                      # 83 cards, 2 per A4 sheet with a cut line
python3 tools/build_staff_pdf.py --layout a5          # exact A5 page per card — no cutting at all
python3 tools/build_staff_pdf.py --layout a4          # one big A4 card per teacher (poster size)
python3 tools/build_staff_pdf.py --only 7,41,66       # just these teachers (rehearsal prints)
python3 tools/build_staff_pdf.py --mode book          # the 29-page staff book instead
```

Every card is built from that teacher's own record — watercolour portrait, name, designation pill,
subject chips, qualification, their section's theme colours, a numbered seal (`37 of 83`), three
small things worth remembering about that subject, and a letter addressed to them by name
(*Dear Ma'am,* / *Dear Father,* / *Dear Sister,*). Where `teacher_context.md` has Pavit's own words
about a teacher, the card quotes them back at that teacher in the second person, and the closing wish
matches what they teach. All 83 cards are laid out by the same code path, so text is shrink-fitted
and measured — no card can spill outside its gilded frame.

**Printing:** choose *Actual size / 100 %* (no “fit to page”, duplex off). Each sheet gives two cards;
cut once along the dashed line in the middle and you have two exact **A5 (210 × 148.5 mm)** cards.
Card stock at 200–300 gsm, or plain A4 with a glue stick behind it, works nicely.

## The print edition — a decorated PDF of the whole staff 📕

`St_Marys_Staff_Book_2019-20.pdf` (29 pages, A4) is the book version of this site: a painted
cover, a contents page with real page numbers, a leadership spotlight, one divider per section,
a card for **every one of the 83 teachers and staff**, the sealed letter and the gratitude wall.

```bash
pip install reportlab pillow            # build-only tools; the site itself stays dependency-free
python3 tools/build_staff_pdf.py --mode book     # regenerates the whole book from the data in this repo
python3 tools/build_staff_pdf.py --mode book --dpi 300 --quality 88 --out /tmp/big.pdf  # print-shop quality
```

`tools/build_staff_pdf.py` reads **the same data the website uses** — `js/data.js` (falling back to
`staff.csv`), plus `teacher_context.md` for the personal notes — so adding a row to the CSV and
re-running the script re-flows the sections, the contents list and every page number automatically.
Nothing about the layout is hand-placed:

- portraits are cropped to circles at build time (from `assets/staff-cards/` → `images/` → initials),
- washes, ribbons, wax seals, garlands and confetti are **vector drawings**, so pages stay crisp at
  any print size and the file stays ~2.5 MB,
- each card's thank-you is Pavit's own note when `teacher_context.md` has something to say, and a
  subject-flavoured line otherwise (rotated so two neighbours never print the same sentence).

The original scan (`St_Marys_Staff_Enhanced_compressed.pdf`) is kept untouched for reference.

## Regenerating data from staff.csv

```bash
# after editing staff.csv
python3 /tmp/gen_staff.py   # regenerates js/data.js + assets/staff-avatars/
```

## Run locally

Any static server works, e.g.

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Accessibility & performance notes

- Semantic landmarks, skip link, labelled form fields and visible focus states.
- `prefers-reduced-motion` is respected (animations & confetti calm down automatically).
- Confetti only appears when *you* click something — nothing auto-sprays on load.
- Fonts load from Google Fonts with graceful fallbacks; everything else is dependency-free.
- With JavaScript disabled, pages degrade gracefully.
